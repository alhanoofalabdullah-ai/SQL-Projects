## 🚀 How to Use

Clone the repository:

```bash
git clone https://github.com/alhanoofalabdullah-ai/SQL-Projects.git
```

Navigate to the repository:

```bash
cd SQL-Projects
```

Open any project folder:

```bash
cd project-21-enterprise-data-warehouse
```

Run the SQL files in the order documented in the project README.

Example using PostgreSQL:

```bash
psql -U postgres -d database_name -f schema.sql
psql -U postgres -d database_name -f sample_data.sql
psql -U postgres -d database_name -f queries.sql
```
